# 缠论信号分析系统
本项目基于缠中说禅理论，实现了一个从 K 线数据中自动识别笔、中枢和买卖点的工具。核心功能包括：
自动划分“笔”并判断方向；
识别 B1/B2/B3 买点与 S1/S2/S3 卖点；
绘制包含笔、中枢、信号的交互式图表。
所有逻辑封装在 chanlun_core.py 中，通过 main.py 调用并生成多种输出文件。
## 思路说明
我尝试用量化方式还原缠论的核心结构。重点在于：
用分型连接成“笔”，作为基本单位；
基于笔的起止价构建中枢；
在中枢上下方寻找背驰信号（B1/S1）和回踩不破结构（B2/S2）；
进一步判断突破后是否形成 B3/S3。
由于行情中存在微小波动，原始条件太严格会导致信号无法触发。因此我在关键位置加入了容差处理，比如允许回调跌破前低最多 1%，让模型在实际数据中更有实用性。
## 方法设计
### 数据输入
支持任意周期的 OHLCV 数据（如 30min）
需要字段：timestamp, open, high, low, close
示例文件：eth_30m_202511_raw.csv
### 核心流程
分型检测：使用 5K 构造顶底分型
笔生成：将连续分型连接为一笔，记录方向、振幅、起止价格
中枢识别：三笔重叠区域构成中枢（下-上-下 或 上-下-上）
信号判断：
    B1/S1：新高/新低 + 振幅 ≤ 前一笔 × 1.1
    B2/S2：回调未有效跌破 B1 / 反弹未有效突破 S1（容差 ±1%）
    B3/S3：突破中枢后回踩未进入中枢（容差 ±0.5%）
### 输出结果
运行后会生成以下四类文件：
chanlun_chart.html：交互式可视化图表
chanlun_export_signals.csv：所有信号点列表
chanlun_export_strokes.csv：每笔的详细信息
eth_30m_202511_merged.csv：合并后的带信号标注的数据（用于后续分析）
## AI 使用方式
开发过程中使用了 GitHub Copilot 辅助编码。主要用途包括：
快速生成函数框架；
将“放宽条件”这类描述转化为具体代码；

但所有逻辑结构、参数设定和判断规则都是我自己设计和调试的，AI 只是提高了效率。
## 局限与改进方向
目前系统还存在一些不足：
只实现了笔级别分析，没有处理线段或更高层级结构；
对跳空行情敏感，可能漏判或误判；
B3/S3 触发条件较严，需要更强的趋势配合；
中枢识别依赖三笔重叠，有时会形成“伪中枢”。
未来可以改进的方向：
加入多周期验证（如 4h 图过滤 30min 信号）
引入成交量因子（如 B2 出现时要求缩量）
动态调整容差（根据 ATR 指标自适应）
导出信号至回测框架进行验证
## 可运行代码
项目包含以下文件：
chanlun_core.py：核心类 ChanAnalyzer 的定义，包含分型、笔、中枢、信号等全部逻辑
main.py：主程序入口，负责加载数据、运行分析、生成图表和导出文件
运行方式：python main.py
执行后会生成：
chanlun_chart.html：交互式图表
chanlun_export_signals.csv：信号列表
chanlun_export_strokes.csv：笔数据
eth_30m_202511_merged.csv：带信号标注的原始数据
## 示例输出
运行后生成的 chanlun_chart.html 显示了如下内容：
K 线图（灰色）
笔（黑色实线）
中枢（蓝色矩形区域）
信号点：
B1：绿色三角
B2：深绿菱形
S1：红色倒三角
S2：深红菱形
以ETH 2025年11月30分钟数据为例，系统成功识别出多个 B1/B2/S1/S2 结构，尤其在震荡区间表现良好。虽然 B3/S3 尚未出现，但整体结构清晰，符合缠论预期。
